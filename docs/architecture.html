Compare → Verify pipeline · owned by core/ · 7 protocols + 2 capabilities
S1
🔍
Detect
Reads what the repo declares and what the live system runs, normalizes both into a State, and classifies every gap as a ghost with a stable signature.
core protocols: InputSource · SourceAdapter · Comparator · adapters: SchemaComparator · ContractComparator · CacheComparator
↓
S2
🔮
Resolve
Checks the cache of proven fixes first. Otherwise proposes one fix per ghost: SQL from Qwen3-235B grounded in Context7 PostgreSQL docs · field metadata for API ghosts · a deterministic warm/delete for cache keys.
core protocol: Resolver · core Cache · agents: MantleResolver · Context7 REST · MockResolver
↓
S3
⛓
Validate — the safety boundary
The LLM's rationale is never trusted. The SQL is parsed into an AST and checked against the operation matrix, bound to the ghost's exact target, and type changes must be in the widening table.
core protocol: Validator · adapters: SQLValidator (sqlglot) · ContractValidator · CacheValidator
↓
S4
⚡
Authorize
A human reads the proposal on the card and clicks Exorcise. Authorization unlocks REVIEW_REQUIRED and BLOCKED ghosts; the validator still runs, and SET / DELETE / TRUNCATE stay forbidden.
core orchestrator gate: apply_one(id, human_authorized=True) · apply_batch()
↓
S5
🕯
Execute
Applies the validated fix: DDL on Postgres with a 30 s connection-level timeout · a GitHub PR per file (DeepSeek v3.2 writes the patch, Qwen3 checks it) · cache warm or delete on the demo API.
core protocols: Executor · BatchExecutor · RollbackSupport · adapters: SQLExecutor · ContractExecutor · CacheExecutor
↓
S6
✝
Verify
Re-reads the live system and re-runs the comparison. Only a ghost that is truly gone is RESOLVED — and only then is its fix written to the cache. The report is saved atomically after every state change.
core protocol: Verifier · core VerificationResult + evidence · Persistence · Cache

Safety boundaries · core + adapters
Operation matrix + target binding
Only listed DDL kinds pass. Index must be exactly ix_<table>_<cols>, declared column order, plain B-tree. Destructive ops fail closed.
SSRF guard · adapters/ssrf.py
Every outbound request — API probes, cache status, Context7, models.py download — checked against tech.md's blocked ranges. No redirects, no proxies.
Token-based redaction
Secrets stripped from headers, queries and JSON before persistence, logging, or the LLM sees them. Errors stored as code + class, never raw text.
AST-enforced skeleton
test_skeleton.py walks core/'s AST: exact file set, no adapter imports, no sqlglot, no domain branching. Checked on every test run.
